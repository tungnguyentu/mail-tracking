# TrackPixl packaging (hypothesis)

**Status:** Product direction note — not billed yet. Aligns messaging and roadmap; does not implement payments.

## ICP

**Job:** Know if the other side **engaged** on important **1:1 Gmail** mail.

**Who:** Anyone on Gmail web with that job — freelancers, job seekers, founders, recruiters, sales solo, and similar.  
**Not:** Bulk ESP / sequence suites / multi-seat CRM.

## Free (must clear free Mailtrack-class bar)

| Include | Rationale (public market signal) |
|---------|----------------------------------|
| Unlimited tracked sends | Category table stakes |
| **No forced branding footer** | Loudest switch pain vs free trackers |
| Sticky Track on/off in Gmail | Core UX |
| Opens as **possible** / secondary | Honesty vs MPP/proxy noise |
| Click tracking | Primary engagement |
| Basic Activity list | Proof of value |
| Desktop notify: clicks + replies (default) | Engagement-first |

## Paid (hypothesis — validate before building billing)

| Candidate unlock | Why |
|------------------|-----|
| Full history / longer retention | Free tools often limit history |
| Reply as first-class (reliability + UX polish) | Differentiator vs open-only free tools |
| Priority / multi-device polish | Later |
| Optional open notifications | Power users |

**Price band to test (not committed):** ~$3–10/user/mo (competitor paid tiers for branding removal / history sit in this zone). Prefer WTP polls over guessing.

## Messaging order (homepage & ads)

1. No forced branding  
2. Engagement-first (click + reply > open noise)  
3. Quiet Gmail for important 1:1 mail  
4. Examples of use (not one demographic)

## Out of scope until evidence

- Sequences, team admin, CRM sync  
- Winning primarily on “free forever with branding”  
- Open-rate as hero metric
